# SCIRS-1.0 architecture qualification

The initial implementation and fixtures are in the [Language Index registry pull request](https://github.com/software-commons/language-index/pull/1). The common contract was exercised with synthetic Language, Runtime, Platform, and Specification cases using the exact SCES-1.0 validator. Each domain exercised two revisions, an exact versioned external relationship, immutable observation or citation inputs, bounded registry changes, and byte-identical rebuilds.

Local regression checks exercised identity retention through renames, bounded candidate imports, separate coverage snapshots, derived incoming edges, duplicate JSON keys, mismatched shards, unresolved relation targets, typed parents, circular lineage, unbound fields, and rejection of export without an active qualification. The fixtures use synthetic evidence and produce no production language findings.

Classification lives inside the record and may change without renaming the file. The shared model leaves identifiers, predicate vocabulary, owned kinds, and technical scope to each index within the common constraints. The production Language Index gates entity bytes against the frozen input commit and matches each published assertion to exact selected SCES claims.
