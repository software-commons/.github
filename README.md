# .github

Organization identity, governance, and shared community standards for Software Commons.

Software Commons is an independent initiative that synthesizes, normalizes, and standardizes software engineering knowledge into open, versioned, interoperable indexes. The [organization profile](profile/README.md) introduces the initiative. This repository publishes its scope, decision-making practices, and community defaults.

- [Index repository and interoperability policy](docs/INDEX_POLICY.md)

## Participation

See the [contribution guide](CONTRIBUTING.md), [code of conduct](CODE_OF_CONDUCT.md), and [support guide](SUPPORT.md). GitHub uses this public `.github` repository to provide default community files and templates. Individual repositories may supply their own files where the evidence, methods, or technical scope require different guidance.
