# Software Commons

Software Commons is an independent initiative dedicated to the systematic discovery, synthesis, normalization, and standardization of software engineering knowledge.

Technical knowledge is distributed across standards, specifications, reference documentation, release histories, and implementation evidence. These sources serve different purposes and often describe the same concepts with different terms, assumptions, or version boundaries. Software Commons develops focused, versioned, machine-readable reference indexes that reconcile these descriptions while preserving source authority, provenance, and distinctions that matter.

The work centers on the representation of existing knowledge. Standards bodies, specification authors, and upstream projects retain authority over their publications and implementations. Downstream projects own their products and engineering decisions. Software Commons operates independently of the organizations and software products that use its resources.

## How the work is organized

The [organization repository](https://github.com/software-commons/.github) contains the profile, governance, and shared community guidance. Future domain indexes will live in separate repositories, each with a defined scope, independently versioned releases, and documented sources and validation methods. Established requirements, interpretations, observations, and open questions will remain distinguishable and traceable to their evidence.

Once indexes are published, independent projects will be able to select the domains they need, pin release versions, and cite stable record identifiers and source revisions. These resources are intended to support development, research, interoperability, and automated reasoning.
